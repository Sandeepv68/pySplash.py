# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in pySplash.py, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please email **hello@sandeepv.in** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

## Response

You can expect an initial response within 72 hours. We will work with you to understand and address the issue before any public disclosure.

## Scope

This policy applies to the pySplash.py package published on PyPI and this GitHub repository.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |
